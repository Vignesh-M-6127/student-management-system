# Student Management System

## About

The Student Management System is a beginner-friendly Python project that helps users manage student records through a menu-driven interface.

## Features

* Add new student records
* View all students
* Search students by roll number
* Delete student records
* Save records using JSON file storage
* Prevent duplicate roll numbers

## Technologies Used

* Python 3
* JSON
* File Handling

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python student_management.py
```

## Learning Outcomes

This project demonstrates Python functions, loops, conditional statements, lists, dictionaries, JSON handling, and file operations.
